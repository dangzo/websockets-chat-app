# WebSockets Chat App in Vue.js

Side project to learn about WebSockets and real-time communication in web applications. This chat app allows users to connect and communicate with each other in real-time using WebSockets.

## Features
- Real-time messaging: Users can send and receive messages instantly.
- User connection status: Users can see who is currently online.
- Simple and intuitive UI: The interface is designed to be user-friendly and easy to navigate.
- Node.js backend: The server is built using Node.js and the `ws` library for handling WebSocket connections.

## Setup

1. Clone the repository:
   ```bash
   git clone
    ```
2. Navigate to the project directory:
   ```bash
   cd websocket-chat-app
   ```
3. Install dependencies for the server:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm run server
   ```
5. Launch the Vue.js frontend:
   ```bash
   npm run dev
   ```
